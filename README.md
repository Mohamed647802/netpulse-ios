# نبض البيانات (NetPulse) — تطبيق iOS متكامل لتتبع وإدارة استهلاك الواي فاي وبيانات الهاتف

تطبيق **iOS أصلي متكامل** مكتوب بلغة **Swift 5.9** وواجهة **SwiftUI** (يدعم **iOS 16.0 فما فوق**)، مصمم بالكامل باللغة العربية واتجاه **RTL** مع دعم كامل للوضع الليلي والنهاري، وجاهز للبناء التلقائي عبر **GitHub Actions** لإخراج ملف `.ipa` قابل للتثبيت مباشرة عبر **Sideloadly / AltStore / SideStore / TrollStore** بدون الحاجة لجهاز Mac أو حساب مطور Apple مدفوع.

---

## الأقسام المستقلة داخل التطبيق

1. **العدّاد والسجل اليومي والجمع المخصص (`CounterAndHistoryView`):**
   - قراءة عدادات النواة الحقيقية عبر `getifaddrs()` (`ifi_ibytes` و `ifi_obytes`) لواجهة الواي فاي (`en0`) وواجهات بيانات الهاتف (`pdp_ip0` إلى `pdp_ip4`).
   - معالجة إعادة تشغيل الهاتف عبر `kern.boottime` (**Reboot-Safe Delta**) ومعالجة التفاف عداد `UInt32` عند `4GB` بحيث لا تضيع أو تتصفر قراءات اليوم عند عمل Restart للآيفون.
   - التعرف على شبكة الواي فاي ببصمة الشبكة المحلية (`Gateway IP + Subnet`) مع إمكانية تسمية كل شبكة بحرية (مثل: "واي فاي البيت"، "واي فاي العمل").
   - قاعدة بيانات `SQLite3` دائمة مع فلترة حسب (`الشبكة الحالية` / `كل الواي فاي` / `داتا الهاتف` / `الكل`).
   - **تحديد أكثر من يوم وجمعها:** تحديد أيام متفرقة من القائمة أو من التقويم الشهري التفاعلي، أو تحديد فترة متصلة (`من تاريخ إلى تاريخ`)، مع أزرار سريعة (`آخر 7 أيام` / `آخر 14 يوم` / `هذا الشهر` / `تحديد الكل` / `إلغاء التحديد`) وبطاقة ملخص جمع فوري عائمة تعرض عدد الأيام، المجموع الكلي (`MB` / `GB`)، مجموع التحميل ↓، مجموع الرفع ↑، والمتوسط اليومي.

2. **عدّاد ومنبّه الاستهلاك المخصص (`CustomUsageAlarmView`):**
   - تحديد أي كمية بحرية مع اختيار الوحدة (`MB` أو `GB`).
   - اختيار نطاق المراقبة (`الواي فاي فقط` / `داتا الهاتف فقط` / `الاثنان معاً`).
   - تحديد نسبة التحذير المسبق عبر شريط التمرير أو الإدخال الرقمي (مثلاً `70%` أو `80%` أو `90%`).
   - عداد دائري بصري مع أزرار (`بدء` / `إيقاف مؤقت` / `تصفير وإعادة ضبط`) ونظام إشعارات ذكي يطلق تنبيهاً صوتياً عند نسبة التحذير وإشعاراً عاجلاً (`Time-Sensitive Alert`) عند `100%` مع خيار تكرار المنبّه عند استمرار السحب.

3. **استهلاك الراوتر بالكامل ومقارنته بالآيفون (`RouterUsageView`):**
   - اكتشاف البوابة الافتراضية تلقائياً والاتصال بالراوتر عبر بروتوكول `UPnP` (`SSDP` + `WANCommonInterfaceConfig` -> `GetTotalBytesReceived` / `GetTotalBytesSent`) مع دعم واجهات إحصائيات الراوترات الشائعة والمزامنة اليدوية المساندة.
   - بطاقة مقارنة بصرية توضح نسبة استهلاك آيفونك اليوم من إجمالي سحب جميع الأجهزة المتصلة بالراوتر.

4. **الباقات المستقلة لكل شبكة (`QuotaManagerView`):**
   - إضافة باقة مستقلة بحجم وموعد تجديد مختلف لكل شبكة على حدة، مع حساب المتبقي، الأيام المتبقية للتجديد، **المعدل اليومي المسموح به**، وتنبيه عند تجاوز المعدل اليومي.

5. **جرس إنذار السحب الخفي المفاجئ (`SpikeAlertView`):**
   - ضبط حد مستقل للواي فاي ولداتا الهاتف (مثلاً `500 MB` خلال `15 دقيقة`) مع إشعار فوري وسجل كامل لحوادث السحب المفاجئ.

6. **حارس الداتا المفتوحة مع الواي فاي و `Wi-Fi Assist` (`DualConnectionGuardView`):**
   - يعمل بمراقبَين منفصلين بالتوازي `NWPathMonitor(requiredInterfaceType: .wifi)` و `NWPathMonitor(requiredInterfaceType: .cellular)` مع فحص عنوان IP على واجهة `pdp_ip0` عبر `getifaddrs()`.
   - يرسل إشعاراً فورياً عند الاتصال بالواي فاي مع بقاء زر الداتا مفتوحاً، ويرصد أي ميجابايت تُسحب بالخلفية عبر `Wi-Fi Assist` مع إمكانية التخصيص لشبكات معينة.

7. **إدارة الصلاحيات (`PermissionsManager` & `PermissionsView`):**
   - شاشة عربية واضحة لفحص وطلب صلاحيات الإشعارات، الشبكة المحلية (`Local Network & Bonjour UPnP`)، التحديث في الخلفية (`BGTaskScheduler`)، والموقع المساند، مع زر فتح إعدادات النظام واختبار الإشعارات الفورية.

8. **النسخ الاحتياطي والويدجت وبناء `.ipa` تلقائياً:**
   - تصدير واستيراد السجلات والنسخ الاحتياطية بصيغتي **JSON** و **CSV**.
   - ويدجت عربية (`WidgetKit`) للشاشة الرئيسية وشاشة القفل.

## طريقة بناء واستخراج ملف `.ipa` عبر GitHub Actions (بدون جهاز Mac)

1. ارفع جميع ملفات هذا المجلد إلى مستودع جديد على حسابك في **GitHub** (عام أو خاص):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: NetPulse iOS App"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/<REPO>.git
   git push -u origin main
   ```
2. افتح تبويب **Actions** في مستودعك على GitHub، فستجد عملية البناء **Build Unsigned iOS IPA** قد بدأت تلقائياً (أو اضغط **Run workflow** لتشغيلها يدوياً).
3. بعد اكتمال البناء (يستغرق نحو 2 إلى 3 دقائق)، افتح صفحة العملية وانزل لقسم **Artifacts** بالأسفل لتحميل:
   - **`NetPulse-IPA`**: يحتوي على ملف `NetPulse.ipa` الكامل (التطبيق + الويدجت).
   - **`NetPulse-Lite-NoWidget-IPA`**: نسخة بدون إضافة الويدجت (مفيدة إذا استنفدت حد الـ App IDs المجاني الأسبوعي في حساب Apple مجاني).
4. فك ضغط ملف الـ ZIP المحمّل لتحصل على ملف `NetPulse.ipa` ثم ثبّته عبر **Sideloadly** أو **AltStore** أو **SideStore** أو **TrollStore**.
